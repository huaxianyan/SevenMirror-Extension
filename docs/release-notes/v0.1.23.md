这一版把弹窗改成未读、历史、设置三页，通知不再只是「手机上还挂着的那些」，读过的会留在本机可以搜到。

## 新功能

- **通知历史**：读过的通知进入历史页，按今天、昨天、日期分组，最多保留 200 条。
- **搜索**：一个输入框同时搜未读与历史，结果按「未读」「历史 · 日期」分组并给出条数；只匹配通知标题与正文，不匹配应用名，全程在本机完成。
- **全部已读**：未读页一键标记，角标随之清零，条目转入历史。打开详情与「全部已读」是同一种标记，三处不会互相矛盾。
- **保留历史开关**：设置页新增「保留通知历史」，默认开启。关闭后只清理手机已经移除的记录，仍在手机上的通知照常保留，回复与清除不受影响。
- **界面重做**：弹窗改为一条通知一张卡，未读与历史用底部两页切换，设置移入右上角；设置页保留左侧分页并换了同一套配色；单条详情窗与配色统一。图标颜色取自项目图标，浅蓝只做装饰，承载文字的填充色用加深版本。

手机仍在显示的通知与已读历史都可以搜到，但只有前者可以回复或清除。手机已经清除的通知在历史里只读，点开不会有动作。

升级只替换扩展，配对、通知设置与快捷操作规则都会保留，不需要重新加入，也不需要升级手机或服务端。

完整行为见 [通知历史与搜索](https://github.com/huaxianyan/SevenMirror-Extension/blob/v0.1.23/docs/notification-history.md)。
