SevenMirror 首次发布，将 Android 手机通知同步到你选择的浏览器，并支持查看详情、远程操作和回复。

## 主要更新

- **通知同步**：手机侧选择应用和接收浏览器，通知内容在扩展内解密。
- **清晰的通知卡片**：独立卡片底色、边框和间距，让通知列表更容易辨认，未查看通知更醒目。
- **远程操作与回复**：从浏览器执行通知操作、清除和回复，手机拒绝清除时提供结果反馈。
- **已查看状态**：工具栏角标按实际打开过的通知详情更新。
- **共享快捷规则**：同一工作区的浏览器可以通过口令共享优先级规则和快捷操作。
- **独立交互窗口**：点击系统通知主体，在独立小窗口中查看详情和操作。

同一扩展身份下的升级保留配对和本地设置。首次安装或扩展身份变化时，需要重新配对。
Release ZIP 可用于提交 Chrome Web Store 审核，发布 Release 不代表已经通过商店审核。

完整实现与验收记录见 [发布溯源文档](https://github.com/huaxianyan/SevenMirror-Extension/blob/v0.1.21/docs/release-provenance.md)。
