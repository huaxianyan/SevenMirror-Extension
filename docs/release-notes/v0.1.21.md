SevenMirror Extension receives notifications from your own phone over an
end-to-end encrypted channel and presents them in the browser you are using.
This is the first tagged release.

## 主要更新

- **Notification mirroring**: only applications you select on the phone can send
  notifications, and only to browsers you have picked as recipients. Decryption
  happens in the extension; the relay never sees plaintext.
- **Remote actions and replies**: mark done, dismiss and free-form replies travel
  back over the same authenticated channel, bound to the exact notification
  revision so a stale view cannot act on newer content.
- **A refused clear is reported**: when Android refuses a remote clear, the
  notification body says why instead of leaving the request unanswered.
- **Badge counts what you opened**: the toolbar badge clears only for
  notifications whose detail you actually opened, not for merely opening the
  popup.
- **Shared shortcut rules**: priority rules and shortcut actions can be shared
  across every browser in your workspace behind a passphrase; the server stores
  only ciphertext and writes are guarded by an optimistic revision check.
- **Independent interaction window**: clicking a notification's body opens a
  small window beside it, so interacting does not add a tab or lose your place.

Upgrades keep your paired identity and local settings, so an existing browser
does not need to re-register. The ZIP in this release is the same deterministic
submission package prepared for Chrome Web Store.
