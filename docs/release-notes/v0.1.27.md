这一版把弹窗和信息排版的粗糙处收干净，另外给设置页加了一个可以自己贴样式的地方。

## 新功能

- **自定义样式**：设置 →「数据与隐私」里可以贴一段 CSS，应用到弹窗、设置页和交互小窗。首次打开预置了一套与网页端一致的排版样式，另有「恢复默认」与「清空」，保存后生效。

## 改进

- 弹窗高度固定为 520 像素，内容少也不会缩成一条，内容多在列表里滚动。
- 「未读 / 历史」切换移进搜索行，底部标签栏移除，列表区域不再被占去一条。
- 通知详情顶部显示应用图标，图标在左、应用信息与标题正文在右，读起来和通知卡片一致。
- 设置页顶栏高度与管理端对齐。
- 设置页排版调整为：标题、标签、说明各自一级，说明文字改用次要色。

## 问题修复

- 悬停图标或「未读 / 历史」时出现蓝色方框与色块，现在只变图标或文字颜色。
- 应用图标后面多出一块白色圆角底板。
- 「清除本地通知列表」悬停时被填成主色蓝，改为红底白字。
- 没有内容时弹窗右侧出现一条滚动条。

界面与滚动规则见 [界面基线](https://github.com/huaxianyan/SevenMirror-Extension/blob/v0.1.27/docs/ui-baseline.md)，已读与历史的判定见 [通知历史与搜索](https://github.com/huaxianyan/SevenMirror-Extension/blob/v0.1.27/docs/notification-history.md)。
