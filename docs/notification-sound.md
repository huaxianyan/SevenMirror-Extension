# 通知提示音

## 行为

扩展使用随包分发的原创提示音，时长为 0.70 秒。
它是用户确认的「A 清脆版」，双音节奏与尾音保持最终试听版本。

- 实时收到的新通知版本，包括更新，在通知成功呈现且静默关闭时播放
- 当前连接收到并验证中继补发完成标记后，才启用实时声音提醒
- 重连补发、快照恢复、重复投递、设置变更和本地通知重绘保持安静
- 来源已隐藏或浏览器通知关闭时，保留现有呈现过滤行为
- 短时间同时到达的通知共用正在播放的声音，避免重叠或反复重启

原生通知固定使用 `silent: true`，声音由扩展播放，避免系统音与独立音叠加。
原来的 `silentNotifications` 偏好直接控制独立声音，升级保留原选择。
「设置 → 通知 → 试听提示音」是主动试听入口，静默开启时也可试听。

## 浏览器边界

增加 `offscreen` 权限，沿用最低 Chrome 116 要求。
后台创建随包提供的静态页面，以 `AUDIO_PLAYBACK` 理由播放本地 WAV。
同一扩展保持一个播放器，浏览器在无音频播放 30 秒后自动关闭该页面。
播放消息只包含操作类型，不传通知内容、回复、设备标识或连接凭据。
不新增远程音频请求、统计服务或网站访问授权。

提示音受浏览器音量和输出设备控制，Windows 系统通知音量或「请勿打扰」可能不阻止独立音频。
需要安静时，使用扩展的「静默浏览器通知」设置。
音频不可用时继续显示通知，用户可在设置中试听检查；试听失败提供重新加载扩展的下一步提示。
播放失败不改变通知接收、协议确认和连接恢复结果。

## 素材来源

文件：`public/sounds/notification.wav`。
生成依据：`scripts/generate_notification_sound.py`，仅使用 Python 标准库。
该脚本只生成最终选定的音效，不保留其他试听候选或变体。

声音从正弦及少量谐波独立合成，没有采样或转写 Pushbullet 录音，也不使用第三方音频素材。
最终音频及生成代码随本项目以 GPL-3.0-only 分发，不另行施加第三方素材许可限制。
不以此声称绝对零法律风险或独占版权。


