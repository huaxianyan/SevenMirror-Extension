# 界面基线

扩展的三个入口（弹窗、设置页、独立交互窗）与管理端使用同一套视觉规则。本文记录这些规则的位置，避免以后各页各改一套。

## 唯一来源

- 颜色、字体、字号、字重、圆角、顶栏、侧栏、卡片、按钮与输入框定义在 `src/shared/sevenmirror-theme.css`，内容对齐服务端管理端的 `internal/adminweb/assets/admin.css`。
- 弹窗与设置页只写各自的布局，不重新定义颜色或控件形状。弹窗另有一层密度别名，把旧变量名映射到公共 token。
- 详情面板的标记与样式在 `src/shared/notification-detail.css`，弹窗与独立交互窗共用。

## 间距节奏

设置页只有一套节奏，写在各页共用的布局规则里：

| 位置 | 间距 |
| --- | --- |
| 面板之间 | `1.25rem` |
| 区块标题到内容 | `1.25rem` |
| 页标题到说明 | `.4rem` |
| 相邻说明行 | `.5rem` |

卡片内的字段只由容器 `gap` 控制，不再叠加全局的输入框外边距。空的状态行与空列表不占高度。

## 悬停

公共主题把普通 `button` 当作主操作按钮，悬停会填充主色。列表行、底栏页签、图标按钮都是 `button`，因此各自用更高特异性的规则改成浅色调：

- 列表行：底色向主色混 6%，并加深边框。
- 底栏页签：不填背景，只加深文字；当前页签保持主色。
- 图标与返回按钮：使用同一层浅色调。

## 滚动

- 只滚正文：设置页的顶栏固定，只有 `.layout` 区域滚动；弹窗的顶栏、搜索框与底栏固定，只有 `#list-view` 与 `#detail-view` 滚动。整页滚动会让滚动条把通栏顶栏的右侧空出一条，看起来像 layout 坏了。
- 滚动容器本身要通栏：设置页的 `.layout` 铺满窗口宽度，滚动条才贴在窗口右缘；72rem 的栏宽收在内层 `.layout-inner` 上。把栏宽放在滚动容器上，滚动条就悬在页面中间。
- 滚动容器上设 `scrollbar-gutter: stable`，滚动条只占正文区域的右侧，且无论有没有滚动条正文宽度都不变。
- 独立交互窗是整页滚动，所以在 `html` 上留位。
- 弹窗用 `height: min(600px, 100vh)` 定高，不用 `max-height`：弹出窗口按内容定尺寸，内容一少弹性列就没有可分配的余量，列表塌成几十像素，空状态也一起被裁掉。顶栏右侧的按钮组固定 36 像素高，切换未读与历史时顶栏高度不变。

## 侧栏

设置页侧栏是 `position: sticky`，它的偏移会被所在列高度夹住。短页面会让导航上跳，因此布局容器保留了至少一屏的高度。
